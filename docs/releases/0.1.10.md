# Folqio v0.1.10 — PDF page safety and photo performance

Folqio keeps PDF source files and in-memory document state unchanged while editing separate copies.

## Improvements
- **Non-destructive iOS page tools:** rotate, reorder, delete, extract, and merge always work from a separate serialized PDFKit document. The caller's loaded reader document is never mutated.
- **Encrypted PDF safety:** unsupported operations will not silently remove an input PDF's password protection.
- **Reduced photo memory use:** iOS photo imports create bounded-size ImageIO thumbnails before PDF composition and honor source EXIF orientation.
- **Regression coverage:** new XCTest cases exercise unchanged source pages across operations, malformed images, oversized photos, and maximum decoded image dimensions.
- **Version alignment:** Android and iOS report Folqio v0.1.10, build 11.

## Important limitations
- Android page extraction, rotation, and merging flatten pages to bitmaps; do not rely on them for retaining selectable text, forms, or digital signatures.
- iOS free-text annotations overlay existing content and do **not** replace the PDF's underlying text; any edit may invalidate signatures.
- The Android APK is a **debug development build** and the AAB remains **unsigned** without the owner's upload key. iOS has simulator builds/tests but no distributable signed IPA.
- Production release additionally requires physical-device visual/accessibility QA, real account signing, full translated-string review, and Play/App Store submissions.
