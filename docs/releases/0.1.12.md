# Folqio v0.1.12 — Android document deletion safety

## Improvements
- **Crash-resilient Android deletion:** App-owned PDFs are first renamed to private UUID tombstones. The recent list, favorites and bookmarks are then committed as a single durable metadata transaction. A failed write restores the original file name.
- **Interrupted-operation recovery:** On app startup, Folqio restores a staged PDF when durable library metadata still references it; an already-committed removal cleans up its tombstone. Other files and invalid names are never processed.
- **Safer removal:** Folqio rejects attempts to delete a document not registered in its library.
- **Responsive quick actions:** Compact Android screens display two short action cards followed by a full-width Photos action; wider screens retain the three-column layout.
- **Regression coverage:** JVM tests for interrupted deletion, successful cleanup, rollback, invalid names and overwrite avoidance.
- Android and iOS version values aligned at **v0.1.12, build 13**.

## Known limitations and distribution
- Android merge/rotate/extract still rasterize original PDF content. This is not lossless page editing or secure redaction.
- Android OCR and existing-text editing remain unavailable. Full translation, real-device visual QA and Android/iOS editor parity are outstanding.
- Development GitHub release: debug APK and unsigned AAB only. A signed Google Play AAB and iOS distributable archive are not provided without proper signing credentials.
