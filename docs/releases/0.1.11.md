# Folqio v0.1.11 — safer photos and blank-page tools

## Changes
- **Android photo safety:** reject files larger than 25 MB when a content provider reports their size, and enforce a separate 25 MB streaming-read ceiling during bounds decoding, bitmap decoding and EXIF inspection. No photo data leaves the device.
- **iOS page editing:** insert a blank A4 page immediately after the selected page in a separate PDF copy using PDFKit; original pages and the source document remain unchanged.
- **iOS page tools UI:** adaptive thumbnail grid for compact phones and iPads, with unavailable move directions disabled.
- **Regression tests:** bounded Android input streams including exact limit and one-byte overflow; iOS blank-page isolation, page geometry and invalid indices.
- **Version alignment:** Android and iOS v0.1.11, build 12.

## Limitations and release status
- Android merges/rotations/extractions still rasterize page content, losing selectable text and vector structure. Do not use for secure redaction.
- Android does not yet offer offline OCR or a true PDF text editor. PDFKit text overlays on iOS do not replace existing PDF text.
- The GitHub release pipeline builds a **debug-signed APK**, an **unsigned Android AAB**, and an iOS simulator build/test. None are production-signed store packages.
- Physical-device testing, extensive translations, PDF security review, performance profiling and store signing remain pending.
