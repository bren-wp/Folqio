# Folqio v0.1.13 — Android-only privacy and document protection

- Android PDF recovery keeps staged deletion bytes when another live PDF of the same name exists. New JVM regressions cover referenced and unreferenced collisions.
- Removed the former iOS app sources, tests, generation tools and macOS/XCTest CI/release jobs; Folqio is Android-only.
- Added source-level Android privacy/manifest, release and Play policy checks. Updated active README, privacy, security, roadmap, QA and store-readiness docs to match **actually implemented Android features**.
- Android versionName 0.1.13 / versionCode 14; the existing applicationId and Folqio/Brendigo identity remain unchanged.

**Current limitations:** Android PDF merge/rotate/extract operations are rasterized, not lossless. No Android OCR, automatic multipage scanning, secure redaction or existing-text editing is supplied.

**Release safety:** Only publish after Android unit tests, lint, release AAB and CI pass. Development debug APK is debug-signed; release AAB is unsigned without private signing secrets and cannot be uploaded to Google Play as a production binary.
